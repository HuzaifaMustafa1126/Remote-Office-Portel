# Module roadmap

## Implemented in Phase 1.1

- Authentication and authenticated profile
- Employees and user accounts
- Roles and permissions
- Audit logs
- Dashboard and responsive navigation

## Reserved for future phases

- Attendance and clock/break tracking
- Leave requests and approval
- Salary and payroll calculations
- Reports

Future tables will reference the stable employee identity. Leave and payroll policy—including approved-leave thresholds and unauthorized-absence deductions—belongs in later modules and is not calculated in this phase.
